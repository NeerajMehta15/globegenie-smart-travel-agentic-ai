INPUT:

- preferences: {preferences}

- Named city or landmark (e.g., "Tokyo", "Paris", "Grand Canyon")

- Small region with defined boundaries (e.g., "Scottish Highlands", "Amalfi Coast")
- User clearly knows where they want to go

- Vague descriptors (e.g., "somewhere warm", "beach destination", "adventure trip")
- Very broad regions (e.g., "Europe", "Asia", "Caribbean")
- No destination specified or "Not specified"
- Multiple potential destinations that need comparison
- Requires destination recommendations based on preferences

ANALYZE:
Consider both the destination field AND preferences to determine specificity.
Example: "warm place" + preferences ["beach"] → still vague, needs full research
Example: "Bali" + preferences ["beach", "nature"] → specific, light research sufficient

OUTPUT:
Return ONLY valid JSON in this exact format:
{
  "decision": "light"
}

OR

{
  "decision": "full"
}

Do not include any explanation or additional text. Only return the JSON object with either "light" or "full" as the decision value.
